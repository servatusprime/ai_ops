# Generated Artifact Graphs

These YAML files are deterministic, non-authoritative projections generated by
`00_Admin/scripts/generate_run_family_views.py`:

- `artifact_dependency_graph.yaml`
- `run_family_graph.yaml`
- `governance_routing_graph.yaml`

Run-family authority remains only in colocated `manifest.yaml` files.
Regenerate with `--repo-root . --write` and verify with `--check`. Never edit a
graph view manually or use it to grant execution, approval, or ownership.

See `00_Admin/specs/spec_artifact_graph_identity.md` and
`00_Admin/specs/spec_run_family_composition.md`.
